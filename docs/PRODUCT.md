> **权威产品行为说明（进 Git）。**

## 1. 产品是什么

**Ridge** 是 macOS 顶部**灵动岛式浮层**应用：贴屏幕刘海（或顶部中线）展示会议、媒体、专注、控制台磁贴与各类瞬时提示，并在菜单栏提供设置入口。

- **平台**：仅 macOS（当前阶段）
- **主交互面**：岛（收起 / 展开）+ 设置大窗 + 菜单栏
- **语气**：正式、克制；用户可见文案走 `L10n`（简体中文）

## 2. 岛壳与基础交互

### 2.1 形态

| 态 | 预期 |
|---|---|
| 收起 | 贴顶刘海形；可有左右待命翼（如左音乐、右专注）或圆岛 / 短 tip |
| 展开 | 向下展开面板；内容由当前页 / tip 撑开，壳层只加统一 chrome 边距 |
| 空态 | 无争夺时 `system.empty`；引导去添加小组件 |

外形约定：**上沿贴顶直角，下沿双圆角**（设置预览与真岛一致）。

### 2.2 悬停与展开 / 收起

- **收起态**：指针移入**刘海热区**才展开（普通悬停不用过大「接近区」）。
- **拖文件靠近**：可用更大接近区，并切到货架相关能力（见控制台货架）。
- **展开态**：用更大保展开热区，避免移到面板中下部就误收；内容区纵滑有宽限，不应滑一半就收岛。
- **收起时机**：指针离开保展开区后安排收起；瞬时 tip 撤完且指针不在岛上时一并 collapse，禁止留下空双翼闪一下。

### 2.3 焦点与点击

- 岛不应「粘键盘」抢走正常输入焦点。
- 岛内可点控件（入会、播放控制、滑条、久坐 +10m 等）须可点中；穿透场景下关闭按钮等不被岛吞掉。
- 设置窗与展开岛重叠时，命中设置窗应穿透到设置。
- **Dock「App」启动台**（系统 `Apps.app` / 旧 Launchpad）与 Siri 启动台打开时，岛必须立刻隐藏让路（层级低于系统遮罩会被盖住，表现为点不开）；**不受**设置「全屏时禁用灵动岛」开关影响。普通 App 绿钮全屏仍跟该开关。

### 2.4 分页

- 内容型小组件默认可左右滑切换页。
- **瞬时通知页禁止左右滑**，也不参与翻页角点。
- 控制台各已开模块各占一页（见 §6）。

## 3. 展示权重与左右布局（核心）

岛上争夺只认 **四档**（高 → 低）：

| 档 | 成员 |
|---|---|
| **A** | 取色 / 框选 |
| **B** | 会议 / 正在播放（媒体） |
| **C** | 浏览器下载 / 专注计时（倒计时 · 正计时） |
| **D** | 瞬时 tip（复制、外设、本机电池、网络、**系统专注**、AI 额度、RAM、进程结束、久坐…） |

同档内次序（仍要遵守）：

- **B**：会议盖播放（会议满岛；音乐会话可仍在）
- **C**：下载高于计时（并排时下载占左或占右翼优先于计时，见下表）

用语：

- **C** 含下载与计时；**不是**系统 Focus
- **系统专注 tip** = **D**
- 旧口误「C 类短提示」= 本表 **D**

新小组件 / tip 上岛前必须先定 A/B/C/D（Agent 须询问，见 `.cursor/rules/island-priority-grades.mdc`）。

### 3.1 形态规则（用户可见预期）

| 场景 | 预期表现 |
|---|---|
| A：取色或框选 | **满岛独占**；清掉排队中的 D；期间新 D 不上岛 |
| B：仅会议 tip | 会议满岛（可含入会按钮）；紧迫度三色见 §5.1 |
| B：会议 + 播放 | **只显示会议满岛**（音乐会话可仍在） |
| B 会议 + C 下载 | **左会议 · 右下载半岛** |
| B 会议 + C 计时 | **左会议 · 右计时** |
| B 会议 + D | **左会议 · 右 D**（D 暂盖右翼下载/计时） |
| B：仅播放 | 收起可为播放小岛；展开为媒体面板 |
| B 播放 + C 下载（± 计时） | **左音乐 · 右下载**；下载结束后右翼再露计时 |
| B 播放 + C 计时 | **左音乐 · 右计时**（收起双翼待命） |
| B 播放 + D | **左音乐 · 右 D**（D 暂盖右翼下载/计时位） |
| C：仅下载（进行中） | **全岛**方案 04：左图标+名；右微环+估速；点按 Reveal；悬停不掀面板 |
| C：仅下载（完成） | **全岛**：左勾+名；右「打开」；约 3s 撤（悬停续命） |
| C：下载 + 计时 | **左下载半岛 · 右计时** |
| C 下载 + D | **左下载 · 右 D** |
| C：仅计时 | 计时 / 加时待命胶囊（不悬停展开）；选时 / 终局才展开面板 |
| C 计时 + D | **左计时 · 右 D** |
| 仅 D（含系统专注 tip） | 按 tip 类型：满岛翼 tip / 紧凑双翼 / 右侧圆岛等（见 §4） |
| 无任何争夺 | 空态岛 |

### 3.2 D 与 C 的关系

- C（下载或计时）已在右翼时来了 D：**D 先盖住右翼**；约 **3 秒**后（悬停延后）原右翼回到下载或计时。
- 系统专注 tip 与其它 D **同等**，不单独抬权重。
- C 常驻旗标（下载 / 计时）**不占用** D 的 FIFO 队列。

### 3.3 多条 D

- 瞬时 D：**同时只展示一条**。
- 后来的进入 FIFO；前一条收起后再出下一条。
- 同 id 刷新：更新当前条，不重复入队。

### 3.4 双翼 flush

- 凡「左右并排」形态，左右为贴刘海的 flush 小岛，**不再抬会议专用双翼宽**。
- 半岛三区默认：**左侧图标贴主数值/文案**，中间弹性留白，右侧仅指示点 / 条 / 律动；勿再把主文案撑到正中。
- RAM / 进程结束**单独**上岛时：紧凑双翼贴刘海；与会议/音乐/计时并排时用标准翼宽。

自动化：`test_islandNoticeLayoutMatrix_*`。

## 4. 瞬时通知（通用通道）

所有「冒一下」的提示走同一通道（产品上不叫第二个「临时小组件」）。

### 4.1 通用行为

| 项 | 预期 |
|---|---|
| 默认停留 | 约 **3 秒**自动收起（「已复制」除外：入场约 0.9s + 定格约 0.5s ≈ 1.4s） |
| 悬停 | 指针在岛上时不自动收；离开后再收（取色/框选手动收；「已复制」不悬停续命） |
| 设置窗开着 | tip 应程序上岛可见、不依赖再移入悬停；**仅**小组件库 / 控制台设计 sticky 页挡无自动收 tip（防连震）；岛测试台 / 普通设置不挡 |
| 收完 | 指针不在岛上 → 收岛，不留空态闪屏 |
| 库与排序 | 瞬时通道本身不进小组件库排序；业务能力可在库里有「开关/配置」（如外设提示、已复制） |

### 4.2 各 tip 类型（用户侧）

| 类型 | 触发 | 形态要点 | 自动收 |
|---|---|---|---|
| 会前提示 | 日历会议进入提前期 | 满岛或左翼会议；紧迫度绿/琥珀/红 | 否（按会议保留策略撤） |
| 已复制 | 复制成功 | 刘海右侧小圆岛 | 是（入场+定格约 1.4s；不悬停续命；普通设置开着仍提示，仅小组件设计 sticky 页跳过） |
| 取色进行中 | 快捷键/入口取色 | 满岛独占 | 否（完成/取消撤） |
| 框选 OCR 进行中 | 快捷键/入口框选 | 满岛独占 | 否 |
| 久坐提醒 | 连续活跃达阈值 | 翼 tip；可操作延后等 | 是 |
| AI 额度告警 | 剩余比例触阈 | 翼 tip | 是 |
| 外设低电 / 满电 / 接入 | 蓝牙等外设事件；**接入宜带电量%**（读得到才显示） | 翼 tip | 是 |
| RAM 高压 | 内存占用 ≥ 阈值且告警开 | 单独：左百分比+RAM，右 App 名；悬停可免打扰/管理 | 是 |
| 进程监视结束 | 控制台监视的进程退出 | 双翼：左短名、右短徽标（`exit 0` / `exit n` / `SIGTERM`）+ 耗时；勿用「被信号终止…」长句 | 是 |
| 本机电池 | 插电 / 满电 / 低电 / 拔电 | 翼 tip（方案 01：笔记本+色点+经典电量条）；与外设分通道；台式静默 | 是 |
| 音量变化（规划） | 系统音量跨档或停手后变化 | 短 tip；防抖，禁止拖滑条每格一条 | 是 |
| 网络 / VPN | 见 §5.14：连接类 + 纯断开；切换时抑制中间断开 | 短 tip；非常驻 | 是 |
| 系统专注模式 | 勿扰 / Focus 开·关·切换（**D**） | 满岛：左图标+模式名 / 右「直到 HH:mm」或「已打开」或「已关闭」+指示；半岛：左图标贴名、右仅指示（开=模式色实心光点，关=空心暗环；关态图标与文字去色偏暗）；需完全磁盘访问 | 是 |
| 浏览器下载 | 下载进行中或落盘完成（见 §5.16） | **C**；单独全岛；与计时并排**左下载右计时**；与 B 音乐并排**右翼半岛**（结束后再露计时）；同时只挂一个 | 进行中否；完成态约 3s（悬停续命） |
| 隔空投送完成（规划） | AirDrop 接收完成（文件 / 联系人 / 链接） | 翼 tip；点按按类型打开 | 是 |

阈值类信息：**只在触阈时瞬时提示**，不做第二个常驻「同信息」内容页。

自动化：`test_islandNoticeBehavior_*`、payload 契约穷尽。

## 5. 内容能力（小组件 / 业务）

设置「小组件」库中可开关、排序（空态与瞬时通道除外）。**全部内容能力默认关闭**；用户在库内打开，或首次引导勾选后批量打开时，再按能力申请对应系统权限。控制台磁贴以库内同款卡片呈现，侧栏不再单独「控制台」页。库卡**整卡可点**进入配置（灰舞台与留白均算热区）；仅右下开关独立，不连带进详情。

### 5.1 会议

- 读系统日历；在「提前 N 分钟」（可配，默认约 10）内上岛提示。
- **紧迫度**（距开始）：
  - \> 5 分钟 → 充裕（满岛绿；**半岛半块为蓝** + 日程图标）
  - ≤ 5 且 > 2 分钟 → 临近（琥珀）
  - ≤ 2 分钟（含已开始）→ 紧急（红）
- 半岛半块图标一律日程线框 `calendar`（非满岛临近视频 / 紧急电波）；充裕态图标与脉冲点用 info 蓝。
- 从事件链接识别平台（Zoom / Meet / Teams / Webex / FaceTime / 腾讯会议 / 飞书 / 钉钉等）并一键入会；应打开会议室，而不是日历网页。
- 点入会后 tip 应消失，且不应被 tick 立刻贴回同一场。
- 「开始后保留提示」：开始即关 / 开始后 N 分钟 / 直到结束（设置可配）。
- 始终单独成内容页，不进控制台组合页。

### 5.2 媒体（正在播放）

- 有系统 Now Playing 会话且在播时上岛；结束后撤回。
- 收起：播放小岛；可与专注并排为**左音乐右专注**。
- 悬停/点按**左音乐翼或刘海**展开媒体大面板（封面、进度、控制）；不依赖点按、也不限刘海正中。
- **左音乐·右专注**时：悬停**右专注翼**不展开媒体，改为 morph 专注操作钮（见 §5.3）。
- 有会议 tip 时用户不应再看到「播放小岛可见」抢焦点的形态（会议盖播放）。
- 单独成页，不进控制台。

### 5.3 专注计时（倒计时 + 正计时）

同一能力、同一岛位权重（§3「专注计时」），提供两种**互斥**模式；同时只跑一种。

#### 倒计时（已有）

- 态：选时 → 计时中 → 可顺延（加时）→ 终局（可填备注，结束时已落库）。
- 计时中岛面：仅**待命胶囊**（左进度环 + 剩余时分；右 `+Nm` / 停止圆钮）；悬停不展开大面板。
- 加时岛面：同布局待命胶囊（环改黄）；仍可 `+Nm` / 停止。
- 与音乐并排时专注在右翼：闲时窄翼只显示图标 + 剩余；**悬停右翼** morph 为 `+Nm` + 停止圆钮（同单独待命），**不**开媒体大面板；悬停保存在整翼（含左右缘），禁止未移出就收回操作钮。
- 终局：切到专注页并**全岛**展示贴刘海双翼 tip（左：绿勾 + 真实时长 `Xm` / 正计时墙钟；右：备注 + 回车）；**高=刘海**（与收起待命齐平，禁止再叠 tip 底距掉出刘海下沿）；从音乐+专注半岛结束时也须占满全岛（撤媒体大面板），**不**因指针不在而秒收；保存或主动离开后才收；**不**再附 `(+Nm)`；壳层顶/底距 0；点回车或回车键写入备注。
- 预设三档（默认 15 / 30 / 60）一键起钟；自定义分钟后点播放起钟；顺延步长可配（如 5/10/15 分）。
- 设置看板：今日记录**左「倒计时」右「正计时」**双栏（不再分预设 / 自定义 / 加时三栏）；倒计时行左上实际时长、右上加时（无则不展示），进度条下不展示达成% / +Nm；正计时行左「秒表」+ 标题 / 时段，右大字墙钟时长。

#### 正计时（已有）

选时岛面「正计时」入口（与自定义倒计时之间竖杠分隔；自定义旁标「倒计时」）一点即起钟；**整颗绿胶囊**（图标 +「正计时」三字）同一热区，AppKit 实现以保证浮层首击；保展开须盖住选时岛全宽，往右移点字不得收岛。

| 项 | 预期 |
|---|---|
| 触发 | 点「正计时」后从 `0` **纯累加**；无目标时长 |
| 收起岛面 | **贴刘海待命胶囊**（同高刘海，无大顶距）；左**绿环** + 已过时长；右**暂停** / **结束**；悬停/翻页**禁止**展开到刘海下方 |
| 时长文案 | 始终至少 `分:秒`，出小时再 `时:分:秒`；岛宽先按分秒档，出小时再加宽；收起宽由 compactSize 驱动，禁止 Preference 缩窄裁左右 |
| 左右边距 | 左 10（对齐媒体收起）/ 右 16（躲开下圆角与结束圆钮）；禁止再对称加大把左环撑空 |
| 不做 | **不到点提醒、无顺延加时**（加时只属于倒计时） |
| 结束 | 用户点结束 → 同款**全岛**双翼 tip 终局；左翼绿勾 + **与进行中同款墙钟**（`分:秒` / `时:分:秒`，勿进位成 `1h 12m`）；半岛结束亦全岛；可填备注并落库；指针离开不秒收；永不自动收工 |
| 与音乐并排 | 仍在**右翼**；闲时绿标 + 时长；**悬停** morph 为暂停 + 结束（不开媒体）；**指针离开右翼后须恢复图标+时长**；**整翼**为热区（图标与时长同点，点时长亦有效）；Controller 钉住右翼至指针真正离开，禁止未出岛就收 |
| 与倒计时 | 互斥；历史按 `kind: countUp` 区分 |
| 设置预览 | 多形态 Tab 含正计时样张（绿环 + 暂停/结束） |

产品边界：正计时是**用户主动起的专注会话**，不是系统时钟、不是会议倒计时、也不是秒表 App 替身；不读系统「计时器」App 状态。

### 5.4 世界时钟 / 股票

- 内容页：城市时区对照、自选股行情等。
- 设置预览用假数据，不因无网/空列表而空壳。

### 5.5 取色 / OCR 框选

- 快捷键触发；进行中满岛提示；结束后可产生复制类 tip。录制快捷键时与其它 Ridge 功能（取色 / 框选 / 下载打开）冲突则拒绝保存并提示。
- OCR 无文字：静默收起，不上岛「未识别到文字」噪声条。

### 5.6 久坐提醒

- 按「连续活跃分钟」等策略触发瞬时 tip；可延后/休息；设置可配阈值与反馈。
- 双槽半岛：站姿图标与分钟数贴左侧，右侧仅脉冲点；满岛仍为左右翼完整形态。

### 5.7 AI 额度

- 设置里配置提供商与阈值；触阈时瞬时 tip，非常驻页。
- 双槽半岛：✦ 与剩余百分比贴左侧，右侧仅脉冲点；满岛仍为左右翼完整形态。

### 5.8 外设提示

- 低电 / 满电 / 接入可分别开关；触阈瞬时 tip。
- 满岛：翼宽比会议 tip **收窄**（可点区地板也须跟外设预备宽，禁止抬成会议翼）；外缘只靠壳层 `notchWingTip` 左右令牌，卡根禁止再叠 padding；左翼设备图标 + 名称（展不开则横向滚动，同音乐歌名）；右翼=`电量%`（接入读得到才显示；满电缺省 100）+ 状态环——接入蓝进度弧 / 满电绿整环+闪电 / 低电红进度弧（弧长跟实际电量）。
- 双槽半岛：左簇图标贴电量%（接入无电量时贴「已连接」）；右侧与满岛同款状态环（不再用横条电量格）。
- 电量列表与磁贴在控制台「电量」模块（§6）。

### 5.9 已复制提示

- 库内可开关；复制成功右侧圆岛；货架关着也可以只开复制 tip（产品允许监测剪贴板）。
- 入场约 0.9s + 定格约 0.5s 后自动收起，**不**再等默认 3s，也**不**因悬停续命。
- 普通设置 / 岛测试台开着仍可上岛；仅小组件库设计 sticky 页为防连震跳过。

### 5.10 RAM 监控与进程树

- 设置侧栏「RAM 监控与进程树」：看占用、阈值、告警开关。
- 默认告警可关；阈值默认约 95%（可调）。
- 触阈上岛 RAM tip；**免打扰 30 分钟**须立刻撤掉当前与队列中的 RAM tip。
- **改阈值或重新打开告警**：须清除免打扰，使新规则立即生效（否则旧 mute 会挡住）。

### 5.11 专注与击键洞察

- 设置侧栏看板：专注记录、击键峰值等（峰值按当日小时桶最大值）。

### 5.12 本机电池（笔记本）

- 库卡：`builtin.macBatteryTip`；与外设 tip **分通道**（设置、文案、投递互不共用）。
- 四态均随小组件总开关（无分项开关）：
  1. **插电**：电池→AC（含优化充电「已接电未在充」）；琥珀橙 `#ff9f0a` + 电量条内闪电
  2. **满电**：接电且 100% / isCharged；翡翠绿 `#30d158`
  3. **低电**：未接电且 ≤ 阈值；珊瑚红 `#ff453a` + 状态点脉动
  4. **拔电**：AC→电池；素白静默，无状态点
- 设置页仅配低电阈值与四态样张；阈值默认 15%（推荐档）。
- 视觉：
  - **满岛**（方案 01）：左笔记本 + 色点，右百分比 + 经典电量条（插电琥珀、条内闪电）
  - **半岛**（C 槽微舱）：笔记本 + 百分比 + 电量条；插电与满岛同琥珀数字/条内闪电；满电/低电整段同色；拔电素白
- 走 secondary（C）瞬时队列，约 3s；可与专注/媒体并排半块。
- 低电阈值可配；低电回升再武装；满电拔电后再武装；启动首轮只播种不刷 tip。
- 监听电源变化（IOPS）即时刷新。
- **禁止**常驻本机电量内容页；台式无内置电池静默。

#### 5.14 网络与 VPN（已有）

**原则**：只 tip「用户最终落在的状态」；切换过程中的中间「断开」一律抑制。纯断开（后面没有紧接着的连接/换路）才 tip 断开。

| tip | 何时出 |
|---|---|
| 已连接 Wi‑Fi | 落到 Wi‑Fi（含：有线→Wi‑Fi、换一个 Wi‑Fi、从无网连上 Wi‑Fi） |
| 已连接以太网 | 落到有线（含：Wi‑Fi→有线、从无网插上有线）；岛上标题「以太网」 |
| 已连接 VPN | VPN 连通（含：换一个 VPN 后新隧道连上） |
| Wi‑Fi 已断开 | **纯**断开 Wi‑Fi，且短窗内没有接着连上 Wi‑Fi / 切到有线 |
| VPN 已断开 | **纯**断开 VPN，且短窗内没有接着连上另一个 VPN |

| 场景 | 应 tip | 不应 tip |
|---|---|---|
| Wi‑Fi ↔ 有线 | 只 tip 终点（「已连接以太网」或「已连接 Wi‑Fi」） | 旧路径的「断开」 |
| 换 Wi‑Fi（断 A → 连 B） | 只 tip「已连接 Wi‑Fi」（B） | 「Wi‑Fi 已断开」 |
| 换 VPN（断旧 → 连新） | 只 tip「已连接 VPN」（新） | 旧 VPN「已断开」 |
| 单纯关 Wi‑Fi / 关 VPN | tip 对应「已断开」 | — |
| 从有网掉到无主路径且无后继 | 可 tip 对应断开（实现时与纯断开同规则） | — |

| 项 | 预期 |
|---|---|
| 形态 | 满岛：左图标+名称（过长滚动）/ 右延迟或「断开」+发光点；半岛：仅图标+名称（连接绿图标 / 断开红图标，名称白） |
| 展示字段 | 连接态：白图标/白名 + 延迟与点同色（&lt;100ms 绿，≥100ms 黄）；Wi‑Fi 断开：红图标 + 原 SSID（读不到则「离线」）白字 +「断开」白字 + 红点；VPN 断开：红盾牌 + 名称白字 +「断开」+ 红点 |
| Wi‑Fi 名称 | macOS 14+ 须「定位」权限（仅用于读 SSID，不追踪）；未授权时退「Wi‑Fi」/「离线」；设置页可授权 |
| VPN 名称 | 系统 VPN 服务名优先；Clash 等系统代理无节点名时尽量显示客户端 App 名，否则「VPN」 |
| 不做网速 | 不展示链路速率 / 吞吐 |
| 合并 | 断开事件先入短窗（约 1.25s）；窗内若出现同族连接或主路径换到另一介质，**丢弃断开 tip**，只出连接 tip |
| VPN 判定 | 主接口为 `utun`/`ipsec`/`ppp` 等 **或** 系统 HTTP/HTTPS/SOCKS/PAC 代理开启（Clash 系统代理也算）；空闲 `utun` 不算 |
| 设置 | 小组件库 `builtin.networkLinkTip` **默认关**；打开时申请定位；详情页五态样张 |
| 不做 | 常驻网速/信号页；不为网络再挂 content 小组件；有线「纯断开」不单独 tip |

#### 5.16 浏览器下载（已有）

监视 `~/Downloads` 临时件生命周期；**不依赖浏览器扩展**。无总长时不画假进度条；速度用临时件涨速估算。不做 Steam / 安装器内下载 / App Store。不装扩展则拿不到官方进度%。

| 项 | 预期 |
|---|---|
| 覆盖 | **Chromium 系**（Chrome / Edge / Brave / Arc；国内 QQ / 360 等同源常见 `.crdownload`）+ **Safari**（`.download`）+ **Firefox**（`.part`）+ Opera（`.opdownload`）；另认若干国内临时后缀（如 `.qqdownload` / `.qbd` / `.xltd` 等，能匹配才上岛） |
| 触发（进行中） | 出现已知临时后缀 → 常驻上岛 |
| 触发（完成） | 临时后缀消失后解析成品（同名 / 短窗内最新非临时文件），size 短窗稳定；rename 竞态会重试；孤儿「下载中」约 1.2s 兜底切完成或撤 |
| 进行中（全岛） | 方案 04：左脉冲下载图标+文件名；右 **16px 微圆环** + 定宽估速；总长优先 Safari / Chromium History，否则同系列估；无总长 → 环不确定慢转；「未确认/Unconfirmed」显示「正在下载」 |
| 完成（全岛） | 左绿勾+文件名；右绿色「打开」AppKit 徽章（可带快捷键徽标） |
| 半岛（并排半翼） | 左文件名 · 右薄荷绿估速；底边蓝→青→绿渐变进度；**悬停 morph「打开」** |
| 权重 | §3：**C**（同档内高于计时）；与 B 并排占右翼 |
| 退出 | **进行中**常驻至完成/替换；**完成态**约 3s 自动撤（悬停续命），点「打开」/快捷键/点按成功后撤；关库开关撤 |
| 点击 | 按设置：默认「用默认 App 打开」，可选「在 Finder 中显示」；路径优先 `Downloads/<fileName>`；全岛完成态右「打开」/半岛悬停「打开」均为 AppKit；idle 点按同动作 |
| 快捷键 | 设置可开关；可录制组合（默认 ⌘O）；与取色 / 框选冲突时拒绝；**完成态驻留期间全局热键**；撤 tip 即注销 |
| 打开 / 访达 | 「用默认 App」；dmg 等一律访达选中；「在 Finder 中显示」用 `activateFileViewerSelecting`；成功后约 1.6s 禁止悬停展开 |
| 布局 | 仅下载 → 全岛；下载+计时 → **左下载 · 右计时**；音乐(+计时)+下载 → **左音乐 · 右下载**（下完再露计时） |
| 多文件 | **同时只挂一个**（最新活动替换）；同路径完成短窗去抖 |
| 与音乐 | **左音乐 · 右下载**；会话与播放并存 |

## 7. 设置与关于

- 统一大窗（菜单栏 / App「设置…」同一套），默认约 1200×620。
- 侧栏：功能（灵动岛、小组件、专注与击键、RAM…）在上；通用、关于贴底。

- 各配置页「恢复默认」用统一按钮样式。
- **设置里的岛预览一律假数据样张**，与真机空数据无关；预览外形与真岛一致（上直角下圆角）；**左下/右下弧度跟「灵动岛」下圆角设置**（库卡与详情同）。

### 7.1 岛测试台（仅本地 DEBUG）

- 正式 Release **不可见**。
