# Ridge 产品说明

> **权威产品行为说明（进 Git）。**  
> 用文字描述「用户应看到什么、怎么交互」。改功能 / 交互 / 展示规则时 **必须同步改本文**，再改代码与自动化。  
> Agent 规则：`.cursor/rules/product-spec.mdc`。  
> 自动化锚点：`RidgeTests`（尤其 `IslandNoticeLayoutMatrixTests` / `IslandNoticeBehaviorTests`）+ `docs/REGRESSION_CATALOG.md`。

本文描述**产品预期**，不是实现手册。实现细节见 `.cursor/rules/*` 与源码注释。

---

## 1. 产品是什么

**Ridge** 是 macOS 顶部**灵动岛式浮层**应用：贴屏幕刘海（或顶部中线）展示会议、媒体、专注、控制台磁贴与各类瞬时提示，并在菜单栏提供设置入口。

- **平台**：仅 macOS（当前阶段）
- **主交互面**：岛（收起 / 展开）+ 设置大窗 + 菜单栏
- **语气**：正式、克制；用户可见文案走 `L10n`（简体中文）

---

## 2. 岛壳与基础交互

### 2.1 形态

| 态 | 预期 |
|---|---|
| 收起 | 贴顶刘海形；可有左右待命翼（如左音乐、右专注）或圆岛 / 短 tip |
| 展开 | 向下展开面板；内容由当前页 / tip 撑开，壳层只加统一 chrome 边距 |
| 空态 | 无争夺时 `system.empty`；引导去添加小组件 |

外形约定：**上沿贴顶直角，下沿双圆角**（设置预览与真岛一致）。

### 2.2 悬停与展开 / 收起

- **收起态**：指针移入**刘海热区**才展开（普通悬停不用过大「接近区」）。
- **拖文件靠近**：可用更大接近区，并切到货架相关能力（见控制台货架）。
- **展开态**：用更大保展开热区，避免移到面板中下部就误收；内容区纵滑有宽限，不应滑一半就收岛。
- **收起时机**：指针离开保展开区后安排收起；瞬时 tip 撤完且指针不在岛上时一并 collapse，禁止留下空双翼闪一下。

### 2.3 焦点与点击

- 岛不应「粘键盘」抢走正常输入焦点。
- 岛内可点控件（入会、播放控制、滑条、久坐 +10m 等）须可点中；穿透场景下关闭按钮等不被岛吞掉。
- 设置窗与展开岛重叠时，命中设置窗应穿透到设置。

### 2.4 分页

- 内容型小组件默认可左右滑切换页。
- **瞬时通知页禁止左右滑**，也不参与翻页角点。
- 控制台各已开模块各占一页（见 §6）。

## 3. 展示权重与左右布局（核心）

权重从高到低：

1. **取色 / 框选 / 会议**（最高）
2. **正在播放（媒体）**
3. **专注计时**
4. **C 类短提示**（复制、久坐、外设、AI 额度、RAM、进程结束等）

### 3.1 形态规则（用户可见预期）

| 场景 | 预期表现 |
|---|---|
| 取色或框选进行中 | **满岛独占**；清掉排队中的 C；期间新 C 不上岛 |
| 仅会议 tip | 会议满岛（可含入会按钮）；紧迫度三色见 §5.1 |
| 会议 + 正在播放 | **只显示会议满岛**（音乐被盖，但播放会话可仍在） |
| 会议 + 专注 | **左会议 · 右专注** |
| 会议 + C | **左会议 · 右 C** |
| 仅播放 | 收起可为播放小岛；展开为媒体面板 |
| 播放 + 专注 | **左音乐 · 右专注**（收起双翼待命） |
| 播放 + C | **左音乐 · 右 C**（C 暂盖右翼专注位） |
| 仅专注 | 收起待命翼或满岛专注面板（视展开） |
| 专注 + C（无会议/音乐） | **左专注 · 右 C** |
| 仅 C | 按 tip 类型：满岛翼 tip / 紧凑双翼 / 右侧圆岛等（见 §4） |
| 无任何争夺 | 空态岛 |

### 3.2 C 与专注的关系

- 专注已在右翼时来了 C：**C 先盖住右翼专注**。
- C 约 **3 秒**自动收起后（悬停在岛上则延后，离开后再收），**专注回到右翼**。
- 专注是常驻旗标，**不占用** C 的 FIFO 队列。

### 3.3 多条 C

- 非专注 C：**同时只展示一条**。
- 后来的进入 FIFO 队列；前一条收起后再出下一条。
- 同 id 刷新：更新当前条，不重复入队。

### 3.4 双翼 flush

- 凡「左右并排」形态，左右为贴刘海的 flush 小岛，**不再抬会议专用双翼宽**。
- RAM / 进程结束**单独**上岛时：紧凑双翼贴刘海；与会议/音乐/专注并排时用标准翼宽。

自动化：`test_islandNoticeLayoutMatrix_*`。

## 4. 瞬时通知（通用通道）

所有「冒一下」的提示走同一通道（产品上不叫第二个「临时小组件」）。

### 4.1 通用行为

| 项 | 预期 |
|---|---|
| 默认停留 | 约 **3 秒**自动收起 |
| 悬停 | 指针在岛上时不自动收；离开后再收（取色/框选除外：手动收） |
| 设置窗开着 | **有自动收的瞬时 tip** 仍应程序上岛可见，不依赖再移入悬停；会议/取色等无自动收的仍可被设置会话挡住 |
| 收完 | 指针不在岛上 → 收岛，不留空态闪屏 |
| 库与排序 | 瞬时通道本身不进小组件库排序；业务能力可在库里有「开关/配置」（如外设提示、已复制） |

### 4.2 各 tip 类型（用户侧）

| 类型 | 触发 | 形态要点 | 自动收 |
|---|---|---|---|
| 会前提示 | 日历会议进入提前期 | 满岛或左翼会议；紧迫度绿/琥珀/红 | 否（按会议保留策略撤） |
| 已复制 | 复制成功 | 刘海右侧小圆岛 | 是 |
| 取色进行中 | 快捷键/入口取色 | 满岛独占 | 否（完成/取消撤） |
| 框选 OCR 进行中 | 快捷键/入口框选 | 满岛独占 | 否 |
| 久坐提醒 | 连续活跃达阈值 | 翼 tip；可操作延后等 | 是 |
| AI 额度告警 | 剩余比例触阈 | 翼 tip | 是 |
| 外设低电 / 满电 / 接入 | 蓝牙等外设事件 | 翼 tip | 是 |
| RAM 高压 | 内存占用 ≥ 阈值且告警开 | 单独：左百分比+RAM，右 App 名；悬停可免打扰/管理 | 是 |
| 进程监视结束 | 控制台监视的进程退出 | 双翼结束结果（成功/失败等） | 是 |
| 浏览器下载完成（规划） | 浏览器下载落盘完成 | 翼 tip；点按打开文件 | 是 |
| 隔空投送完成（规划） | AirDrop 接收落盘完成 | 翼 tip；点按打开文件 | 是 |

阈值类信息：**只在触阈时瞬时提示**，不做第二个常驻「同信息」内容页。

自动化：`test_islandNoticeBehavior_*`、payload 契约穷尽。

## 5. 内容能力（小组件 / 业务）

设置「小组件」库中可开关、排序（空态与瞬时通道除外）。控制台磁贴以库内同款卡片呈现，侧栏不再单独「控制台」页。

### 5.1 会议

- 读系统日历；在「提前 N 分钟」（可配，默认约 10）内上岛提示。
- **紧迫度**（距开始）：
  - \> 5 分钟 → 充裕（绿）
  - ≤ 5 且 > 2 分钟 → 临近（琥珀）
  - ≤ 2 分钟（含已开始）→ 紧急（红）
- 从事件链接识别平台（Zoom / Meet / Teams / Webex / FaceTime / 腾讯会议 / 飞书 / 钉钉等）并一键入会；应打开会议室，而不是日历网页。
- 点入会后 tip 应消失，且不应被 tick 立刻贴回同一场。
- 「开始后保留提示」：开始即关 / 开始后 N 分钟 / 直到结束（设置可配）。
- 始终单独成内容页，不进控制台组合页。

### 5.2 媒体（正在播放）

- 有系统 Now Playing 会话且在播时上岛；结束后撤回。
- 收起：播放小岛；可与专注并排为**左音乐右专注**。
- 悬停/点按小岛展开媒体大面板（封面、进度、控制）。
- 有会议 tip 时用户不应再看到「播放小岛可见」抢焦点的形态（会议盖播放）。
- 单独成页，不进控制台。

### 5.3 专注计时（倒计时 + 正计时）

同一能力、同一岛位权重（§3「专注计时」），提供两种**互斥**模式；同时只跑一种。

#### 倒计时（已有）

- 态：选时 → 计时中 → 可顺延（加时）→ 终局（可填备注，结束时已落库）。
- 计时中 / 加时：收起可显示待命翼；与音乐并排时在右。
- 终局应切到专注页并展开，便于命名/确认。
- 预设一键起钟；自定义分钟后开始；顺延步长可配（如 5/10/15 分）。

#### 正计时（规划中）

| 项 | 预期 |
|---|---|
| 触发 | 用户在专注计时里选「正计时」后开始；从 `00:00` 向上累加 |
| 收起 | 与倒计时同槽：待命翼显示已过时长；与音乐并排时仍在**右翼** |
| 展开 | 可暂停 / 继续 / 结束；**无目标终点、无顺延加时**（加时只属于倒计时） |
| 结束 | 用户手动结束 → 终局（可填备注并落库）；不自动到点收工 |
| 与倒计时 | 切换模式须先结束当前会话；历史可按模式区分（或同表标注模式） |
| 设置预览 | 多形态 Tab 含正计时样张 |

产品边界：正计时是**用户主动起的专注会话**，不是系统时钟、不是会议倒计时、也不是秒表 App 替身；不读系统「计时器」App 状态。

### 5.4 世界时钟 / 股票

- 内容页：城市时区对照、自选股行情等。
- 设置预览用假数据，不因无网/空列表而空壳。

### 5.5 取色 / OCR 框选

- 快捷键触发；进行中满岛提示；结束后可产生复制类 tip。
- OCR 无文字：静默收起，不上岛「未识别到文字」噪声条。

### 5.6 久坐提醒

- 按「连续活跃分钟」等策略触发瞬时 tip；可延后/休息；设置可配阈值与反馈。

### 5.7 AI 额度

- 设置里配置提供商与阈值；触阈时瞬时 tip，非常驻页。

### 5.8 外设提示

- 低电 / 满电 / 接入可分别开关；触阈瞬时 tip。
- 电量列表与磁贴在控制台「电量」模块（§6）。

### 5.9 已复制提示

- 库内可开关；复制成功右侧圆岛；货架关着也可以只开复制 tip（产品允许监测剪贴板）。

### 5.10 RAM 监控与进程树

- 设置侧栏「RAM 监控与进程树」：看占用、阈值、告警开关。
- 默认告警可关；阈值默认约 95%（可调）。
- 触阈上岛 RAM tip；**免打扰 30 分钟**须立刻撤掉当前与队列中的 RAM tip。
- **改阈值或重新打开告警**：须清除免打扰，使新规则立即生效（否则旧 mute 会挡住）。

### 5.11 专注与击键洞察

- 设置侧栏看板：专注记录、击键峰值等（峰值按当日小时桶最大值）。

### 5.12 浏览器下载完成提示（规划中）

**首期只接浏览器下载完成**，不做通用「任意进程写 Downloads」、不做下载进度常驻页。

| 项 | 预期 |
|---|---|
| 触发 | 常见浏览器（至少 Safari；Chrome / Edge 视可行性）把文件**下载完成**到本机下载目录（或浏览器约定落点） |
| 进行中 | **不上岛**进度条 / 常驻下载页（首期明确不做） |
| 完成 | 走通用瞬时通道（§4）：短 tip，约 3s（悬停保活） |
| tip 文案 | 克制：文件名（过长截断）+「下载完成」类状态；不堆路径全文 |
| 点击 tip | **打开该文件**（系统默认 App；失败则在 Finder 中显示） |
| 多文件 | 连下多份：各算一条 C，FIFO 排队；同文件重复完成不刷屏 |
| 开关 | 小组件库可关；关掉则不监听 / 不上 tip |
| 预览 | 设置样张含满岛 tip + 末档半岛（左音乐 · 右下载完成） |

例外 / 不做（首期）：

- App Store、系统更新、`curl` / 终端、网盘同步、隔空投送（见 §5.13）不走本通道
- 不代替浏览器自己的下载栏；Ridge 只做「完成后的岛上结果」
- 不在 tip 上提供「取消下载 / 暂停」（完成态无此操作）

权限预期：以能可靠感知「浏览器下载完成 + 文件路径」为准；若系统要求额外权限，在设置「通用 / 权限」里说明，拒绝则静默降级（无 tip、无死循环弹窗）。

### 5.13 隔空投送（AirDrop）接收提示（规划中）

| 项 | 预期 |
|---|---|
| 触发 | 本机**接收** AirDrop **完成**（文件已落到本机） |
| 形态 | 通用瞬时 tip（§4），约 3s；可与音乐并排为半岛 |
| 文案 | 「隔空投送」+ 文件名（或「N 项」）；不展示发送方隐私细节过头（姓名可显示若系统已给出） |
| 点击 | 打开刚接收的文件 / 在 Finder 显示（与下载完成同一交互口径） |
| 进行中 | **不做**系统级「正在接收、接受/拒绝」代替（系统 UI 仍负责）；Ridge 只做**完成后的结果 tip** |
| 开关 | 库内可关 |
| 与下载 | 独立 tip 类型；权重同 C；FIFO 共用 |

不做（首期）：发送方进度、替系统弹接受框、多设备广播管理。

## 6. 控制台

控制台 = 功能性磁贴页集合（音量、货架、项目释放、电量），**不承载**会议/媒体等内容型业务页。

| 模块 | 预期 |
|---|---|
| 货架与剪贴板 | 拖文件靠近可磁吸入舱；可配磁吸开关；与复制 tip 协作 |
| 输出音量 | 系统/应用音量；按 App 音量应对准宿主进程 |
| 项目释放 | 扫描本地项目占用；可释放；**监视进程**（同时只监视一个，点另一个替换）；结束上岛 tip 仅对应当前监视对象 |
| 电量与外设 | 外设电量列表；可排序；点击行为可配 |

- 模块默认可关；开启后占岛分页。
- 电量类实况：开启后可先邀请再点进（产品上「点进才上岛」的路径与面板类直接切页可区分）。

## 7. 设置与关于

- 统一大窗（菜单栏 / App「设置…」同一套），默认约 1200×620。
- 侧栏：功能（灵动岛、小组件、专注与击键、RAM…）在上；通用、关于贴底。
- 灵动岛：主题、下圆角曲率、触觉等。
- 通用：开机自启、权限汇总（日历、屏幕录制、输入监控、蓝牙等）。
- 关于：版本、法律、反馈。
- 各配置页「恢复默认」用统一按钮样式。
- **设置里的岛预览一律假数据样张**，与真机空数据无关；预览外形与真岛一致（上直角下圆角）。
- 可与音乐并排的 tip（外设 / AI 额度 / 久坐 / 会议 / 已复制等）配置页预览末档为 **半岛**：左音乐半块 + 右 tip 半块（或右「已复制」圆岛），示意 dualFlush，不代表会常驻上岛。

### 7.1 岛测试台（仅本地 DEBUG）

- 正式 Release **不可见**。
- 供开发者手动穷举：tip 停留覆盖、专注快进、写真实日历会议、拉起监视进程、外设/控制台注入、组合剧本。
- **不是**给终端用户的功能；自动化回归仍以 `RidgeTests` 逻辑测为准，测试台补真机手感。

## 10. 维护约定（给研发 / Agent）

1. **改产品行为 → 先/同时改本文对应小节**（预期描述、表格行、例外）。
2. 若行为已有 recurring 自动化：同步改 `RidgeTests` 与必要时 `REGRESSION_CATALOG.md`。
3. 新瞬时 tip：本文 §4 加行 + `IslandNoticePayload` 契约测必须覆盖。
4. 新布局组合：核对 §3 真值表文字是否仍成立；跑 `./scripts/test-recurring.sh`。
5. 仅实现细节、无用户可感差异：可只改代码/规则，不必硬改本文；有疑虑时偏保守更新本文。
