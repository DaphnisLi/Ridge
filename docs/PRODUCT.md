# Ridge 产品说明

> **权威产品行为说明（进 Git）。**  
> 用文字描述「用户应看到什么、怎么交互」。改功能 / 交互 / 展示规则时 **必须同步改本文**，再改代码与自动化。  
> Agent 规则：`.cursor/rules/product-spec.mdc`。

## 1. 产品是什么

**Ridge** 是 macOS 顶部**灵动岛式浮层**应用：贴屏幕刘海（或顶部中线）展示会议、媒体、专注、控制台磁贴与各类瞬时提示，并在菜单栏提供设置入口。

- **平台**：仅 macOS（当前阶段）
- **主交互面**：岛（收起 / 展开）+ 设置大窗 + 菜单栏
- **语气**：正式、克制；用户可见文案走 `L10n`（简体中文）

## 2. 岛壳与基础交互

### 2.1 形态

| 态 | 预期 |
|---|---|
| 收起 | 贴顶刘海形；可有左右待命翼（如左音乐、右专注）或圆岛 / 短 tip |
| 展开 | 向下展开面板；内容由当前页 / tip 撑开，壳层只加统一 chrome 边距 |
| 空态 | 无争夺时 `system.empty`；引导去添加小组件 |

外形约定：**上沿贴顶直角，下沿双圆角**（设置预览与真岛一致）。

### 2.2 悬停与展开 / 收起

- **收起态**：指针移入**刘海热区**才展开（普通悬停不用过大「接近区」）。
- **拖文件靠近**：可用更大接近区，并切到货架相关能力（见控制台货架）。
- **展开态**：用更大保展开热区，避免移到面板中下部就误收；内容区纵滑有宽限，不应滑一半就收岛。
- **收起时机**：指针离开保展开区后安排收起；瞬时 tip 撤完且指针不在岛上时一并 collapse，禁止留下空双翼闪一下。

### 2.3 焦点与点击

- 岛不应「粘键盘」抢走正常输入焦点。
- 岛内可点控件（入会、播放控制、滑条、久坐 +10m 等）须可点中；穿透场景下关闭按钮等不被岛吞掉。
- 设置窗与展开岛重叠时，命中设置窗应穿透到设置。

### 2.4 分页

- 内容型小组件默认可左右滑切换页。
- **瞬时通知页禁止左右滑**，也不参与翻页角点。
- 控制台各已开模块各占一页（见 §6）。

## 3. 展示权重与左右布局（核心）

权重从高到低：

1. **取色 / 框选 / 会议**（最高）
2. **正在播放（媒体）**
3. **专注计时**
4. **C 类短提示**（复制、久坐、外设、AI 额度、RAM、进程结束等）

### 3.1 形态规则（用户可见预期）

| 场景 | 预期表现 |
|---|---|
| 取色或框选进行中 | **满岛独占**；清掉排队中的 C；期间新 C 不上岛 |
| 仅会议 tip | 会议满岛（可含入会按钮）；紧迫度三色见 §5.1 |
| 会议 + 正在播放 | **只显示会议满岛**（音乐被盖，但播放会话可仍在） |
| 会议 + 专注 | **左会议 · 右专注** |
| 会议 + C | **左会议 · 右 C** |
| 仅播放 | 收起可为播放小岛；展开为媒体面板 |
| 播放 + 专注 | **左音乐 · 右专注**（收起双翼待命） |
| 播放 + C | **左音乐 · 右 C**（C 暂盖右翼专注位） |
| 仅专注 | 计时 / 加时为待命胶囊（不悬停展开）；选时 / 终局才展开面板 |
| 专注 + C（无会议/音乐） | **左专注 · 右 C** |
| 仅 C | 按 tip 类型：满岛翼 tip / 紧凑双翼 / 右侧圆岛等（见 §4） |
| 无任何争夺 | 空态岛 |

### 3.2 C 与专注的关系

- 专注已在右翼时来了 C：**C 先盖住右翼专注**。
- C 约 **3 秒**自动收起后（悬停在岛上则延后，离开后再收），**专注回到右翼**。
- 专注是常驻旗标，**不占用** C 的 FIFO 队列。

### 3.3 多条 C

- 非专注 C：**同时只展示一条**。
- 后来的进入 FIFO 队列；前一条收起后再出下一条。
- 同 id 刷新：更新当前条，不重复入队。

### 3.4 双翼 flush

- 凡「左右并排」形态，左右为贴刘海的 flush 小岛，**不再抬会议专用双翼宽**。
- 半岛三区默认：**左侧图标贴主数值/文案**，中间弹性留白，右侧仅指示点 / 条 / 律动；勿再把主文案撑到正中。
- RAM / 进程结束**单独**上岛时：紧凑双翼贴刘海；与会议/音乐/专注并排时用标准翼宽。

自动化：`test_islandNoticeLayoutMatrix_*`。

## 4. 瞬时通知（通用通道）

所有「冒一下」的提示走同一通道（产品上不叫第二个「临时小组件」）。

### 4.1 通用行为

| 项 | 预期 |
|---|---|
| 默认停留 | 约 **3 秒**自动收起（「已复制」除外：入场约 0.9s + 定格约 0.5s ≈ 1.4s） |
| 悬停 | 指针在岛上时不自动收；离开后再收（取色/框选手动收；「已复制」不悬停续命） |
| 设置窗开着 | tip 应程序上岛可见、不依赖再移入悬停；**仅**小组件库 / 控制台设计 sticky 页挡无自动收 tip（防连震）；岛测试台 / 普通设置不挡 |
| 收完 | 指针不在岛上 → 收岛，不留空态闪屏 |
| 库与排序 | 瞬时通道本身不进小组件库排序；业务能力可在库里有「开关/配置」（如外设提示、已复制） |

### 4.2 各 tip 类型（用户侧）

| 类型 | 触发 | 形态要点 | 自动收 |
|---|---|---|---|
| 会前提示 | 日历会议进入提前期 | 满岛或左翼会议；紧迫度绿/琥珀/红 | 否（按会议保留策略撤） |
| 已复制 | 复制成功 | 刘海右侧小圆岛 | 是（入场+定格约 1.4s；不悬停续命；普通设置开着仍提示，仅小组件设计 sticky 页跳过） |
| 取色进行中 | 快捷键/入口取色 | 满岛独占 | 否（完成/取消撤） |
| 框选 OCR 进行中 | 快捷键/入口框选 | 满岛独占 | 否 |
| 久坐提醒 | 连续活跃达阈值 | 翼 tip；可操作延后等 | 是 |
| AI 额度告警 | 剩余比例触阈 | 翼 tip | 是 |
| 外设低电 / 满电 / 接入 | 蓝牙等外设事件；**接入宜带电量%**（读得到才显示） | 翼 tip | 是 |
| RAM 高压 | 内存占用 ≥ 阈值且告警开 | 单独：左百分比+RAM，右 App 名；悬停可免打扰/管理 | 是 |
| 进程监视结束 | 控制台监视的进程退出 | 双翼：左短名、右短徽标（`exit 0` / `exit n` / `SIGTERM`）+ 耗时；勿用「被信号终止…」长句 | 是 |
| 本机电池 | 插电 / 满电 / 低电 / 拔电 | 翼 tip（方案 01：笔记本+色点+经典电量条）；与外设分通道；台式静默 | 是 |
| 音量变化（规划） | 系统音量跨档或停手后变化 | 短 tip；防抖，禁止拖滑条每格一条 | 是 |
| 网络 / VPN（规划） | Wi‑Fi↔有线切换、VPN 通/断 | 短 tip；非常驻 | 是 |
| 系统专注模式（规划） | 勿扰 / Focus 开·关·切换 | 短 tip；不承诺读全部分门细则 | 是 |
| 浏览器下载完成（规划） | 浏览器下载落盘完成 | 翼 tip；点按按设置打开 | 是 |
| 隔空投送完成（规划） | AirDrop 接收完成（文件 / 联系人 / 链接） | 翼 tip；点按按类型打开 | 是 |

阈值类信息：**只在触阈时瞬时提示**，不做第二个常驻「同信息」内容页。

自动化：`test_islandNoticeBehavior_*`、payload 契约穷尽。

## 5. 内容能力（小组件 / 业务）

设置「小组件」库中可开关、排序（空态与瞬时通道除外）。控制台磁贴以库内同款卡片呈现，侧栏不再单独「控制台」页。

### 5.1 会议

- 读系统日历；在「提前 N 分钟」（可配，默认约 10）内上岛提示。
- **紧迫度**（距开始）：
  - \> 5 分钟 → 充裕（满岛绿；**半岛半块为蓝** + 日程图标）
  - ≤ 5 且 > 2 分钟 → 临近（琥珀）
  - ≤ 2 分钟（含已开始）→ 紧急（红）
- 半岛半块图标一律日程线框 `calendar`（非满岛临近视频 / 紧急电波）；充裕态图标与脉冲点用 info 蓝。
- 从事件链接识别平台（Zoom / Meet / Teams / Webex / FaceTime / 腾讯会议 / 飞书 / 钉钉等）并一键入会；应打开会议室，而不是日历网页。
- 点入会后 tip 应消失，且不应被 tick 立刻贴回同一场。
- 「开始后保留提示」：开始即关 / 开始后 N 分钟 / 直到结束（设置可配）。
- 始终单独成内容页，不进控制台组合页。

### 5.2 媒体（正在播放）

- 有系统 Now Playing 会话且在播时上岛；结束后撤回。
- 收起：播放小岛；可与专注并排为**左音乐右专注**。
- 悬停/点按小岛展开媒体大面板（封面、进度、控制）。
- 有会议 tip 时用户不应再看到「播放小岛可见」抢焦点的形态（会议盖播放）。
- 单独成页，不进控制台。

### 5.3 专注计时（倒计时 + 正计时）

同一能力、同一岛位权重（§3「专注计时」），提供两种**互斥**模式；同时只跑一种。

#### 倒计时（已有）

- 态：选时 → 计时中 → 可顺延（加时）→ 终局（可填备注，结束时已落库）。
- 计时中岛面：仅**待命胶囊**（左沙漏进度环 + 剩余时分；右 `+Nm` / 停止圆钮）；悬停不展开。
- 加时岛面：同布局待命胶囊，进度环等强调色改为黄色；仍可 `+Nm` / 停止。
- 与音乐并排时专注在右翼（窄翼只显示环/图标 + 剩余，无操作钮）。
- 终局应切到专注页并展开，便于命名/确认。
- 预设三档（默认 15 / 30 / 60）一键起钟；自定义分钟后点播放起钟；顺延步长可配（如 5/10/15 分）。

#### 正计时（规划中）

选时岛面已露出「正计时」入口（与自定义倒计时之间竖杠分隔；自定义旁标「倒计时」）；点按后的累加会话尚未接通。

| 项 | 预期 |
|---|---|
| 触发 | 用户在专注计时里选「正计时」后开始；从 `00:00` **纯累加** |
| 收起 | 与倒计时同槽：待命翼显示已过时长；与音乐并排时仍在**右翼** |
| 展开 | 可暂停 / 继续 / 结束 |
| 不做 | **不设目标时长、不到点提醒、无顺延加时**（加时只属于倒计时） |
| 结束 | 用户手动结束 → 终局（可填备注并落库）；永不自动到点收工 |
| 与倒计时 | 切换模式须先结束当前会话；历史可按模式区分（或同表标注模式） |
| 设置预览 | 多形态 Tab 含正计时样张 |

产品边界：正计时是**用户主动起的专注会话**，不是系统时钟、不是会议倒计时、也不是秒表 App 替身；不读系统「计时器」App 状态。

### 5.4 世界时钟 / 股票

- 内容页：城市时区对照、自选股行情等。
- 设置预览用假数据，不因无网/空列表而空壳。

### 5.5 取色 / OCR 框选

- 快捷键触发；进行中满岛提示；结束后可产生复制类 tip。
- OCR 无文字：静默收起，不上岛「未识别到文字」噪声条。

### 5.6 久坐提醒

- 按「连续活跃分钟」等策略触发瞬时 tip；可延后/休息；设置可配阈值与反馈。
- 双槽半岛：站姿图标与分钟数贴左侧，右侧仅脉冲点；满岛仍为左右翼完整形态。

### 5.7 AI 额度

- 设置里配置提供商与阈值；触阈时瞬时 tip，非常驻页。
- 双槽半岛：✦ 与剩余百分比贴左侧，右侧仅脉冲点；满岛仍为左右翼完整形态。

### 5.8 外设提示

- 低电 / 满电 / 接入可分别开关；触阈瞬时 tip。
- 满岛：左翼一律设备图标 + 名称；右翼=`电量%`（接入读得到才显示；满电缺省 100）+ 状态环——接入蓝进度弧 / 满电绿整环+闪电 / 低电红进度弧（弧长跟实际电量）。
- 双槽半岛：左簇图标贴电量%（接入无电量时贴「已连接」）；右侧与满岛同款状态环（不再用横条电量格）。
- 电量列表与磁贴在控制台「电量」模块（§6）。

### 5.9 已复制提示

- 库内可开关；复制成功右侧圆岛；货架关着也可以只开复制 tip（产品允许监测剪贴板）。
- 入场约 0.9s + 定格约 0.5s 后自动收起，**不**再等默认 3s，也**不**因悬停续命。
- 普通设置 / 岛测试台开着仍可上岛；仅小组件库设计 sticky 页为防连震跳过。

### 5.10 RAM 监控与进程树

- 设置侧栏「RAM 监控与进程树」：看占用、阈值、告警开关。
- 默认告警可关；阈值默认约 95%（可调）。
- 触阈上岛 RAM tip；**免打扰 30 分钟**须立刻撤掉当前与队列中的 RAM tip。
- **改阈值或重新打开告警**：须清除免打扰，使新规则立即生效（否则旧 mute 会挡住）。

### 5.11 专注与击键洞察

- 设置侧栏看板：专注记录、击键峰值等（峰值按当日小时桶最大值）。

### 5.12 本机电池（笔记本）

- 库卡：`builtin.macBatteryTip`；与外设 tip **分通道**（设置、文案、投递互不共用）。
- 四态均随小组件总开关（无分项开关）：
  1. **插电**：电池→AC（含优化充电「已接电未在充」）；琥珀橙 `#ff9f0a` + 电量条内闪电
  2. **满电**：接电且 100% / isCharged；翡翠绿 `#30d158`
  3. **低电**：未接电且 ≤ 阈值；珊瑚红 `#ff453a` + 状态点脉动
  4. **拔电**：AC→电池；素白静默，无状态点
- 设置页仅配低电阈值与四态样张；阈值默认 15%（推荐档）。
- 视觉：
  - **满岛**（方案 01）：左笔记本 + 色点，右百分比 + 经典电量条（插电琥珀、条内闪电）
  - **半岛**（C 槽微舱）：笔记本 + 百分比 + 电量条；插电与满岛同琥珀数字/条内闪电；满电/低电整段同色；拔电素白
- 走 secondary（C）瞬时队列，约 3s；可与专注/媒体并排半块。
- 低电阈值可配；低电回升再武装；满电拔电后再武装；启动首轮只播种不刷 tip。
- 监听电源变化（IOPS）即时刷新。
- **禁止**常驻本机电量内容页；台式无内置电池静默。
### 5.13～5.18 规划中能力（仿苹果岛节奏；尚未实现）

下列一律走通用瞬时通道（§4），**禁止**另造第二套「临时上岛」widget；库内可开关。与苹果原生 Live Activities **不是**同一 SDK，Ridge 只采集本机状态自己上岛。

#### 5.13 音量变化轻提示（规划中）

| 项 | 预期 |
|---|---|
| 触发 | 系统输出音量变化（键盘/触控条/部分外设旋钮等） |
| 防抖 | **禁止**拖滑条每格一条；停手后再 tip，或跨明显档位才 tip |
| 形态 | 极短 tip（音量图标 + 百分比或条）；不抢会议/取色 |
| 与控制台 | 混音台面板仍保留；本项只是瞬时反馈，非常驻音量页 |

#### 5.14 网络与 VPN（规划中）

| 项 | 预期 |
|---|---|
| 触发 | Wi‑Fi ↔ 有线等主路径切换；VPN **连通 / 断开** |
| 形态 | 短 tip（如「已连 Wi‑Fi · 名称」/「VPN 已连接」）；约 3s |
| 不做 | 常驻网速/信号页；SSID 隐私敏感时可用泛化文案 |

#### 5.15 系统专注模式切换（规划中）

| 项 | 预期 |
|---|---|
| 触发 | 系统 Focus / 勿扰 **开启、关闭或切换模式** |
| 形态 | 短 tip（模式名若可读则显示） |
| 边界 | 系统可读性有限：做「切换提示」即可，**不承诺**读全部分门别类细则或替系统改 Focus |
| 与 §5.3 | 本项是**系统 Focus**；与 Ridge「专注计时」无关、不同名同义 |

#### 5.16 浏览器下载完成（规划中）

**首期只接浏览器下载完成**；不做进度常驻；不做 Steam / 安装器内下载 / App Store。

| 项 | 预期 |
|---|---|
| 触发 | Safari（及可行时 Chrome / Edge）下载**落盘完成** |
| 进行中 | **不上岛**进度条 |
| tip | 文件名 +「下载完成」；约 3s |
| 点击 | **按设置**：默认「用默认 App 打开」；可选「在 Finder 中显示」；打开失败回退 Finder |
| 多文件 | FIFO；同文件不刷屏 |
| 开关 | 库内可关 |

#### 5.17 隔空投送接收（规划中）

接收**完成后**的结果 tip；**文件 / 联系人 / 链接都要**。一律 §4。货架磁吸面**已去掉**「隔空传送」舱（§6），发送隔空走系统分享等既有路径。

| 类型 | tip 摘要 | 点击 |
|---|---|---|
| 文件 | 文件名 | 与下载同口径（默认真认 App，可设 Finder） |
| 联系人 | 「联系人」+ 姓名（若有） | 打开通讯录 / 卡片 |
| 链接 | 主机或截断 URL | 默认浏览器打开 |

- 不做「正在接收 / 接受·拒绝」代替系统 UI。
- 库内可关；类型分开关能做就做，否则首期总开关。

#### 5.18 明确不做（本阶段）

| 项 | 原因 |
|---|---|
| 系统时钟 App Timer 真接入 | 无稳定公开订阅 API；正计时是 Ridge 自建（§5.3），写明非系统时钟 |
| 来电 / FaceTime 接听 | 无正规 API；与系统提示叠两套体验差；**不做** |
| 系统录屏/录音指示 | 无稳定公开「系统正在录」API；只做本 App 录无价值；**不做** |
| Steam / 商店内下载进度 | 私有进度接不进；**不做** |
| 系统 Live Activities 宿主 | 第三方接不进苹果给其它 App 的通道 |

## 6. 控制台

控制台 = 功能性磁贴页集合（音量、货架、项目释放、电量），**不承载**会议/媒体等内容型业务页。

| 模块 | 预期 |
|---|---|
| 货架与剪贴板 | 拖文件靠近可磁吸**暂存入舱**（单暂存面，无隔空舱）；可配磁吸开关；与复制 tip 协作。隔空接收结果见 §5.17 |
| 输出音量 | 系统/应用音量；按 App 音量应对准宿主进程；音量变化短 tip 见 §5.13 |
| 项目释放 | 扫描本地项目占用；可释放；**监视进程**（同时只监视一个，点另一个替换）；结束上岛 tip 仅对应当前监视对象 |
| 电量与外设 | 外设电量列表；可排序；点击行为可配 |

- 模块默认可关；开启后占岛分页。
- 电量类实况：开启后可先邀请再点进（产品上「点进才上岛」的路径与面板类直接切页可区分）。

## 7. 设置与关于

- 统一大窗（菜单栏 / App「设置…」同一套），默认约 1200×620。
- 侧栏：功能（灵动岛、小组件、专注与击键、RAM…）在上；通用、关于贴底。
- 灵动岛：主题、下圆角曲率、触觉等。

- 关于：版本、法律、反馈。
- 各配置页「恢复默认」用统一按钮样式。
- **设置里的岛预览一律假数据样张**，与真机空数据无关；预览外形与真岛一致（上直角下圆角）。

### 7.1 岛测试台（仅本地 DEBUG）

- 正式 Release **不可见**。
- 供开发者手动穷举：tip 停留覆盖、专注快进、写真实日历会议、拉起监视进程、外设/控制台注入、组合剧本。
- 工具与图鉴均**按组件分卡**（会议 / AI / 久坐 / RAM / 进程 / 外设 / 取色·OCR·已复制 / 媒体 / 专注 / 世界时钟·股价 / 控制台）：每卡「上岛状态」穷举该组件形态，可选「调试工具」；投到**真岛**，状态与图鉴假数据对齐。
- 页下方「样式图鉴」同样按组件分卡；有半岛的 tip 与整岛并排（半岛只画自身半翼）；**点击样张**投递到真岛。
- 工具只驱动正式路径（假数据 / 快进），展开与挡 tip 规则与正式一致：仅小组件库设计 sticky 挡无自动收 tip。
- 「一键清除全部测试数据」：撤 tip、关假媒体、清外设注入与进程监视、删测试日历会议、复位专注选时与 tip 时长覆盖并收岛。
- **不是**给终端用户的功能；自动化回归仍以 `RidgeTests` 逻辑测为准，测试台补真机手感。
